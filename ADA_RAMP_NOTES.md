# ADA / Accessibility Notes — Ramps (Care Construction reference)
Compiled from our ADA sheet (ADA Standards / A117.1 sections we use). Guidelines — verify against local code / AHJ.

## Slope & rise
- Running slope **1:12 max = 4.76°** (code). We build to **5°** because it's easier to find on a speed square — slightly steeper than code, so keep runs short.
- **405.6 Rise:** **30" max** rise for any single ramp run before a level landing.
- **303.4:** any change in level over **½"** must be ramped.
- Rise at 5° (build reference table):
  4'→4.2" · 5'→5.25" · 6'→6.3" · 7'→7.35" · 8'→8.4" · 10'→10.5" · 12'→12.6" · 16'→16.8" · 18'→18.9" · 20'→21" · 22'→23.1" · 24'→25.2" · 28'→29.4" · **30'→30" (max; 5° would give 31.5")**

## Clear width
- **405.5:** clear width of a ramp run — and, where handrails are provided, the clear width **between handrails** — **36" min**.
  (Frame wider than 36" so the *clear* dimension between rails still nets 36".)

## Landings & turns
- **405.7:** level landings at the **top and bottom of every run**; length **60" min**; **at least as wide as the ramp**.
- **Change of direction / 180° turn:** level landing **60" × 60" min** (Advisory 405.7 — no compound slope through a turn).
- **403.5.2 (clear width at 180° turn):** **42" min each side** (or **36" min** exception); spacing between the two ramps **X < 48"**.

## Hairpin gap (between the two parallel ramps)
- Spacing between ramps must be **less than 48"**.
- Handrail clearance requires a **minimum of 1.5"**.
- So: **1.5" ≤ gap < 48".**  (App flags the gap on switchbacks.)

## Handrails
- **505.4 Height:** **34"–38"** above the ramp surface, consistent along the run.
- **505.5 Clearance:** **1.5" min** between the gripping surface and adjacent surfaces.
- **505.10.1 Extensions:** **12" min** horizontal extension at top and bottom (the returns).

## Door threshold & top landing (at the door)
- Threshold: level surface at, or **≤ ½" below**, the house floor height.
- Most homes are a **PUSH** entry → our **48" × 48"** top landing meets the **48" × 42"** min (front push).
- **PULL** door: **60" straight out** from the door **+ 18" beyond the latch side**.
- **404.2.4 maneuvering clearances** (Table 404.2.4.1, perpendicular / parallel to doorway):
  - Front pull **60 / 18** · Front push **48 / 0**
  - Hinge pull **60 / 36** (or **54 / 42**) · Hinge push **42 / 22**
  - Latch pull **48 / 24** · Latch push **42 / 24**
  - (add 6"–12" where a closer/latch is provided — see table footnotes)

## Notes on turns (from our sheet)
- **405.7** bars **curvilinear** (helical / curved) ramps — they create compound slopes.
- A flat landing with an **angled take-off** may be acceptable if the **403.5** space/clearances are met and the **30" max run** isn't exceeded — under research; angle discharge isn't prohibited where clearance is met, and can save lumber.
